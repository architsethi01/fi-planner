# Financial Independence Planner

A free, single-file financial independence calculator for the **United States, India and the United Kingdom**.

**Live:** https://architsethi01.github.io/fi-planner/

## What it does

- **Real tax engines** for three countries — US federal MFJ brackets, India's new-regime slabs (with rebate, surcharge and cess), UK bands including the personal-allowance taper above £100,000
- **Local account types** — 401(k), HSA, backdoor Roth / EPF, PPF, NPS, ELSS / ISA, SIPP, LISA
- **Line-by-line spending builder** — rent or mortgage, car owned/financed/leased, EMIs or student loans
- **Separates debt that ends from spending that continues**, which is where most FI calculators overstate the target
- **Full FI vs Coast FI** modelled separately
- **Cost-of-living adjustment** for where you live now and where you plan to retire
- **20-year asset class returns**, shown nominal *and* real, because a 12% return with 6% inflation is not a 12% return
- Currency-aware formatting, including lakh and crore

## Privacy

Everything runs locally in your browser. No figures are transmitted, stored or collected. No analytics, no cookies, no accounts. Closing the page discards everything. The single HTML file is the whole application — read it and verify.

Download `index.html` and open it in a browser. No build step, no dependencies.
